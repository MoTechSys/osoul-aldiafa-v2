# 02 — نظام الصفحات: كيف تُبنى ٥٤ صفحة

> **الفكرة الحاكمة:** ٢٥ صفحة محلية تُولَّد من **مسار ديناميكي واحد** + **سجل واحد**.
> هذا يعني: إضافة صفحة = **سطر بيانات**، لا ملف راوت ولا قالب تصميم جديد.

---

## الأرقام

| المقياس | العدد |
|---|---|
| صفحات مبنية في `next build` | **٥٤** |
| مداخل `sitemap.xml` | **٤٨** |
| صفحات من المسار الديناميكي | **٢٥** |
| الفرق (٥٤ − ٤٨) | صفحات نظام + `noindex` (`/luxe-demo`, `404`, …) |

---

## سلسلة التوليد

```
src/lib/pages/{jeddah,yanbu,national,regions}.ts   ← البيانات
                    ↓
        src/lib/pages/registry.ts                  ← يدمج ويتحقق
                    ↓
   ┌────────────────┴────────────────┐
   ↓                                 ↓
src/app/[serviceCity]/page.tsx    src/app/sitemap.ts
generateStaticParams()            يقرأ نفس السجل
   ↓
components/LocalServicePage.tsx    ← قالب العرض الموحّد
```

**الفائدة الحاسمة:** المسار والـsitemap يقرآن **نفس المصدر** ⇒ يستحيل أن توجد صفحة خارج الخريطة أو مدخل sitemap بلا صفحة.

## توزيع السجل

| المجموعة | الملف | العدد |
|---|---|---|
| جدة | `pages/jeddah.ts` | ٨ |

## كيف تضيف صفحة — الطريقة الصحيحة الوحيدة

### ١) قبل الكود: اجتَز اختبار المشروعية (٣ أسئلة إجبارية)
| # | السؤال | «لا» ⇒ |
|---|---|---|
| ١ | هل الباحث يريد شيئًا **مختلفًا فعلًا**؟ | ❌ لا تُنشئها |
| ٢ | هل تستطيع كتابة **٨٠٠+ كلمة فريدة** لا تصلح لغيرها؟ | ❌ لا تُنشئها |
| ٣ | هل فيها **معلومة لا توجد في أي صفحة أخرى**؟ | ❌ لا تُنشئها |

### ٢) اختبار القبول القاسي
> **بدّل اسم المدينة في النص. إن بقي كل ما فيه صحيحًا ⇒ الصفحة Doorway ⇒ ارفضها.**

### ٣) أضف السطر في ملف المجموعة المناسب
`registry.ts` يرمي خطأ فوريًا عند slug مكرر — لا تتجاوزه.

### ٤) اربطها
- **≥ ٣ روابط داخلية داخل النص** بنص وصفي (L1/L2)
- **مرتبطة من صفحتين قائمتين على الأقل** (L3) — الصفحة اليتيمة تُصنَّف «جزيرة» في تشخيص جوجل الرسمي

### ٥) قِس قبل الدمج
```bash
node scripts/similarity.mjs <slug-الجديد> <أقرب-٣-صفحات-تنافسه>
npm run check:all
```
🔴 **قِس بالعائلة لا بكامل الموقع.** تمرير ٤٠ صفحة يخفض «الكلمات الحصرية» ميكانيكيًا — السبب الكامل في `04-research/01` §٥.

## ⛔ ممنوعات معمارية

| ممنوع | لماذا |
|---|---|
| ملف راوت جديد لصفحة محلية | يكسر وحدة المصدر ويُخرجها من الـsitemap |
| قالب تصميم جديد | التصميم الأول فقط — قرار صاحب المشروع |
| **صفحة لأي حي** | ٤٠ صفحة ⇒ نصفها Doorway ⇒ **−٦٣٪ زيارات/٣٠ يومًا**. حقل `districts` **نصّ داخل الصفحة فقط** |
| صفحة لصيغة إملائية (`فجدة`, `قهوجيه`) | جوجل يصحّح إملائيًا قبل الترتيب. مكانها **حملة Ads** لا صفحة |
| صفحة لكل مترادف (`صبابين`/`قهوجيين`) | نظام المترادفات يغطّيها. صفحة واحدة تذكرها كلها نصًّا |

## مؤشرات إنذار بعد النشر

| المؤشر | المصدر | الإجراء |
|---|---|---|
| `Crawled, currently not indexed` | Search Console | 🔴 **صفحتان أو أكثر خلال ١٤ يومًا ⇒ أوقف كل التوسّع فورًا.** هذه أبكر إشارة لتصنيف Doorway، وتظهر **قبل** انهيار الترتيب |
| صفحات مكرّرة بلا canonical | Search Console | يجب أن يبقى صفرًا |
