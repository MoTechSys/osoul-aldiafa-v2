# 01 — الخريطة الكاملة للمشروع

> كل مجلد وكل ملف وما يفعله. مبني على **مسح فعلي للكود** لا على تخمين.
> إجمالي ملفات `.ts/.tsx`: **٩٨** · منها **٣٤** مكوّن عميل (`"use client"`).

---

## المكدّس التقني

| البند | القيمة | ملاحظة مهمة |
|---|---|---|
| الإطار | **Next.js 14.2.35** (App Router) | ⚠️ ليس Cloudflare/Hono — النشر على **Vercel** |
| اللغة | TypeScript 5 (`strict`) | `npm run typecheck` بوابة إلزامية |
| التنسيق | Tailwind CSS 3 | 🔴 ملف الأنماط في **`src/styles/globals.css`** لا `src/app/globals.css` |
| الحركة | `motion` v12 | ⚠️ ممنوع فوق الطية — راجع `03-standards/03` |
| الكاروسيل | Embla Carousel | |
| الاختبار | Vitest (وحدة) · Playwright 1.60 + axe-core (E2E/وصول) | Playwright **محلي للمشروع** ⇒ شغّله من جذر `webapp` |

### المسار الديناميكي — قلب النظام
```
src/app/[serviceCity]/page.tsx
```
يولّد **٢٥ صفحة** ستاتيكيًا من سجل واحد عبر `generateStaticParams`.
⚠️ **لا تُنشئ ملف راوت جديدًا لصفحة محلية.** أضف سطرًا في السجل فقط — راجع `02-نظام-الصفحات.md`.

### ملفات النظام
`layout.tsx` (الجذر · `template: "%s | أصول الضيافة"`) · `template.tsx` · `loading.tsx` · `error.tsx` · `global-error.tsx` · `not-found.tsx` (404 حقيقي لا soft-200) · `sitemap.ts` (**٤٨ مدخلًا**) · `robots.ts`
