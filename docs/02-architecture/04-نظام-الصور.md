## 🔴 الصور المرفوضة — أخطر بند في هذا الملف

بعض الصور فيها **وجوه مطموسة (censored)**. صورة كهذه في موضع البطل = **أول ما يراه الزائر** وهي أيضًا عنصر LCP.

**حصل فعلًا:** `setup-5.webp` (وجوه مطموسة) كانت في موضع البطل على الرئيسية.

الحماية القائمة الآن في `images.ts`:
```ts
export const HERO_IMAGES = {
  /** @deprecated وجوه مطموسة — استخدم HERO_SAFE.desktop */
  desktop: "/images/setups/setup-5.webp",
  ...
};

export const HERO_SAFE = { ... };        // ✅ المصدر الصحيح للبطل (setup-9)
export const REJECTED_FOR_HERO = [ ... ]; // قائمة صريحة بالمرفوض
```

**وأُغلقت ثغرة إضافية:** `HERO_IMG` و`HERO_MOBILE_IMG` كانا تصديرين **ميتين** (صفر مستهلك) يشيران للصورة المرفوضة — حُذفا حتى لا يلتقطهما مطوّر لاحق.

| قاعدة | |
|---|---|
| موضع البطل | **`HERO_SAFE` فقط** |
| قبل استخدام أي صورة في موضع بارز | راجع `REJECTED_FOR_HERO` |
| صورة جديدة مطموسة | تُضاف للقائمة المرفوضة فورًا |

## التصديرات الرئيسية

| التصدير | المحتوى |
|---|---|
| `HERO_SAFE` | ✅ صور البطل المعتمدة |
| `REJECTED_FOR_HERO` | ⛔ القائمة المرفوضة |
| `TEAM_IMAGES` · `PRODUCT_IMAGES` · `SETUP_IMAGES` · `DATES_IMAGES` · `DRINK_IMAGES` | مصفوفات المجموعات |
| `PREMIUM_SETUPS` · `PREMIUM_PRODUCTS` · `PREMIUM_DATES` · `PREMIUM_DRINKS` | المختارة للعرض البارز |
| `CLEAN_IMAGES` · `CLEAN_ALT` | المجموعة النظيفة + نصوصها |
| `PORTFOLIO_IMAGES` · `SERVICE_IMAGES` · `OFFERINGS_*` | بطاقات المعرض والخدمات |
| `IMAGE_ALT` + `imageAlt(src, fallback)` | **نص بديل عربي وصفي لكل صورة** |

## قواعد التنفيذ

| # | القاعدة |
|---|---|
| P1 | ❌ ممنوع `<img>` خام — **`next/image` دائمًا** (إلا SVG صغير مضمّن) |
| P2 | `sizes` **إلزامي** مع `fill` — بدونه يُحمَّل أعرض مقاس |
| P3 | `priority` + `fetchPriority="high"` لصورة LCP **واحدة فقط** لكل صفحة |
| P4 | كل ما دونها `loading="lazy"` |
| P5 | `width`/`height` أو `aspect-ratio` دائمًا — منع CLS |
| P6 | `placeholder="blur"` فوق الطية |
| P7 | التسليم: **AVIF ثم WebP** |
| P8 | أقصى عرض مصدر **1920px** |
| P9 | ❌ لا صورة خلفية CSS للمحتوى المهم (تتأخر عن الاكتشاف) |
| P10 | **كل صورة `alt` عربي وصفي غير مكرّر** — الحالة اليوم: صفر صورة بلا alt ✅ |

## ⛔ لا تُعِد ضغط الأصول

**جُرّب وفشل:** Pillow ينتج WebP **أكبر** من الأصل، و`cwebp` غير مثبّت في البيئة.
الاستثناء الناجح الوحيد كان **تصغير أبعاد** لا إعادة ضغط: `logo-192.webp` (٧٣ KB → **١٥.٤ KB**، −٧٩٪) لأيقونة الـmanifest.

التفصيل الكامل في `04-research/01-دروس-مكلفة.md` §٦.

---

## ⏳ ما بقي (ت-١)

الرئيسية تحمّل **٤٨١ KB صورًا** — أثقل صفحة في الموقع.
السبب: `PhotoMarquee` فيه **٨٨ صورة في ٤ أشرطة** بلا `loading="lazy"`، و`Mosaic` مثلها.
الإصلاح ميكانيكي ومضمون، ولم يُنفّذ بعد.

## صورة المعاينة (OG)

`public/og-image.jpg` — **٥٥,١٥٢ بايت**، مولّدة عبر `scripts/make-og.py`، **متحقَّق منها بصريًا** ✅

🔴 **مزلق النص العربي:** Pillow في هذه البيئة فيه `raqm: True` (تشكيل HarfBuzz أصلي).
استخدام `arabic_reshaper` + `python-bidi` معه يسبّب **عكسًا مزدوجًا** («الضيافة أصول»).
الصحيح:
```python
draw.text((x, y), text, font=f, anchor="ma", direction="rtl", language="ar")
```
⚠️ لا يُكتشف هذا الخطأ إلا **بصريًا** — لا اختبار آلي يمسكه.
