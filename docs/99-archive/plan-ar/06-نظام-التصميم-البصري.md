# 06 — نظام التصميم البصري

**المالكون:** D4 (الرئيسية والمكوّنات) · D5 (التنقل والتفاعل) · D6 (قوالب الصفحات المحلية)
**القاعدة:** لا يخترع أحد لوناً ولا مقاساً ولا ظلاً. **كل قيمة بصرية تأتي من هذا الملف.**

---

## 0. الهوية — لا تُمَسّ

الهوية البصرية الحالية **قوية ومناسبة للقطاع** (ضيافة فاخرة سعودية). عملنا **ترسيخها وتوثيقها**، لا استبدالها.

**الاسم:** Royal Champagne · Onyx · Pearl
**الشعور المطلوب:** فخامة هادئة · وقار · نظافة — **لا** بريق مبالغ ولا ازدحام.

> ⚠️ **دَين قائم:** `tailwind.config.js` يحوي **9 أسماء لونية قديمة** (`luxury-black`, `gold-matte`, `charcoal`, `cairo`…) تشير إلى نفس القيم. **الموجة 1:** توحيدها على الأسماء المعتمدة أدناه وحذف الأسماء الميتة (N7 في `03`).

| الرمز | القيمة | الاستخدام |

| البند | القيمة |
|---|---|

## 4. المكوّنات — العقد البصري

### 4.1 الأزرار

| النوع | الخلفية | النص | الاستخدام |
|---|---|---|---|
| **أساسي** | `gold` | `noir` (8.06:1 ✅) | واتساب · اتصال — **واحد فقط لكل شاشة** |
| **ثانوي** | شفاف + حد `gold` | `gold` | إجراء داعم |
| **نصي** | شفاف | `gold-bright` | روابط داخل المحتوى |

| البند | القيمة |
|---|---|
| ارتفاع أدنى | **48px** (المعيار 44 — نزيد للأمان) |
| حشوة أفقية | 24px |
| نصف قطر | 8px (ثابت في الموقع كله) |
| الوزن | 700 · 17px |
| Hover | سطوع +8% · `translateY(-2px)` |
| Active | `translateY(0)` |
| **Focus** | `outline: 2px solid var(--gold-bright); outline-offset: 3px` **إلزامي** |
| Disabled | opacity .45 · `cursor: not-allowed` |

### 4.2 البطاقات
`bg-onyx` · حد `1px rgba(197,160,89,.18)` · نصف قطر 12px · حشوة 20px جوال / 28px مكتب · ظل `royal-card` · Hover: `onyx-elevated` + رفع 4px + حد `gold-deep`.
❌ ممنوع أكثر من مستوى ارتفاع واحد داخل البطاقة.

### 4.3 الصور داخل التصميم
| # | القاعدة |
|---|---|
| V1 | نسب معتمدة فقط: **16:9** (هيرو) · **4:3** (معرض) · **1:1** (فريق) |
| V2 | `aspect-ratio` معلن دائماً — منع CLS |
| V3 | زوايا 12px تطابق البطاقات |
| V4 | تعتيم ≥ 55% خلف أي نص فوق صورة |
| V5 | ❌ ممنوع فلتر ذهبي على وجوه الأشخاص |
| V6 | Hover: `scale(1.03)` بحد أقصى · 400ms |

### 4.4 التنقل السفلي (`BottomNav`)
| البند | القيمة |
|---|---|
| الارتفاع | 64px + `env(safe-area-inset-bottom)` |
| الخلفية | `noir-rich` + `backdrop-blur(12px)` |
| العناصر | **≤ 5** · كل عنصر ≥ 44×44 |
| النشط | `gold-bright` + خط علوي 2px + `aria-current="page"` |
| غير النشط | `pearl-muted` |
| الظهور | جوال فقط (< 768px) |

> 🔴 **تنبيه أداء:** الملف 380 سطراً — يُراجَع لتقليل حمولة العميل (`04` §4.1).

### 4.5 النماذج
تسمية ظاهرة دائماً (❌ placeholder كتسمية) · حقل ≥ 48px · حد `1px onyx-mid` → عند التركيز `gold` · الخطأ: **لون + أيقونة + نص عربي واضح** (C7) · `inputMode="tel"` للهاتف · `dir="ltr"` للأرقام داخل حقل RTL.

## 5. الحركة

### 5.1 المدد
| النوع | المدة | التسارع |
|---|---|---|
| دقيق (hover, focus) | 150ms | `ease-out` |
| قياسي (بطاقة, قائمة) | 250ms | `cubic-bezier(.4,0,.2,1)` |
| دخول القسم | 400ms | `ease-out` |
| ❌ أي شيء | **> 600ms ممنوع** | |

### 5.2 🔴 الأنيميشن اللانهائي — أخطر بند في الملف

الموقع يشغّل **أربع حركات بلا نهاية**: `goldShine` (5s) · `kenburns` (18s) · `floaty` (6s) · `shimmer` (3s).

**الأثر على 96% من زوارنا (جوال):** استهلاك CPU وبطارية مستمر · خطر على مستخدمي حساسية الحركة · ضغط على INP.

**الإجراءات الإلزامية:**

| # | الإجراء | المالك |
|---|---|---|
| M1 | تطبيق `prefers-reduced-motion` عالمياً (الكود في `03` §9) | D5 — الموجة 0 |
| M2 | **حد أقصى حركة لانهائية واحدة** مرئية في الشاشة الواحدة | D4 |
| M3 | `kenburns` على صورة الهيرو فقط — ولا شيء غيرها | D4 |
| M4 | إيقاف أي حركة خارج إطار الرؤية (`IntersectionObserver`) | D5 |
| M5 | ❌ ممنوع أنيميشن يحرّك `width`/`height`/`top`/`right` — **`transform` و`opacity` فقط** | الجميع |
| M6 | ❌ ممنوع كاروسيل يعمل تلقائياً فوق الطية | D4 |
| M7 | ❌ ممنوع parallax على الجوال | D4 |

## 6. RTL — أخطاء يجب ألّا تتكرر

| # | القاعدة | ❌ خطأ | ✅ صحيح |
|---|---|---|---|
| R1 | خصائص منطقية دائماً | `ml-4` · `pr-2` | `ms-4` · `pe-2` |
| R2 | محاذاة منطقية | `text-right` | `text-start` |
| R3 | الأيقونات الاتجاهية تنعكس | سهم «التالي» يمينه | يسار في RTL |
| R4 | ❌ الأيقونات غير الاتجاهية **لا تنعكس** | قلب الشعار/الساعة | اتركها |
| R5 | الأرقام والرموز اللاتينية | تنكسر داخل نص عربي | `dir="ltr"` + `unicode-bidi: isolate` |
| R6 | رقم الهاتف | `+966 56 899 7316` معكوساً | غلّفه في `<bdi>` |
| R7 | لا تمرير أفقي على 375px | — | اختبار E15 إلزامي |

## 7. الأيقونات
SVG مضمّن فقط · `currentColor` · مقاس 20/24/32 · `stroke-width: 1.5` · **≤ 30 أيقونة** في الموقع كله.
❌ ممنوع خط أيقونات كامل (Font Awesome) — `04` §9 X4.
كل أيقونة تفاعلية لها `aria-label` · كل أيقونة زخرفية لها `aria-hidden="true"`.

## 8. اللغة البصرية — قواعد تحريرية

| # | القاعدة | السبب |
|---|---|---|
| L1 | **مساحة بيضاء (سوداء) سخية** | الفخامة تُبنى بالفراغ لا بالامتلاء |
| L2 | ❌ ممنوع أكثر من **إجراء أساسي واحد** لكل شاشة | تشتيت = خسارة تحويل |
| L3 | الصورة تخدم النص، لا تزيّنه | صورة بلا وظيفة = وزن مهدور |
| L4 | ❌ ممنوع أيقونات عامة (stock icons) تحت كل عنوان | ازدحام بلا معنى |
| L5 | ❌ ممنوع «شارات ثقة» بأرقام غير موثّقة | **R9** — E-E-A-T |
| L6 | ✅ صورة حقيقية من مناسبة حقيقية > أي رسم | مصداقية |
| L7 | نبرة صفحة العزاء **وقورة**: بلا ذهب لامع، بلا أنيميشن، بلا تعجّب | احترام السياق |
