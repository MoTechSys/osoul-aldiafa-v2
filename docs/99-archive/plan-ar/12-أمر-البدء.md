## 4. الأسئلة التي ستُسأل — الأجوبة الجاهزة

| السؤال | الجواب |
|---|---|
| «لماذا 38 صفحة فقط وليس 86؟» | حالة موثّقة: 40 صفحة مدينة → نصفها صُنّف Doorway → **−63% زيارات في 30 يوماً**. ومنافسنا `kahwgysa.com` يتصدّر **4 استعلامات بـ5 صفحات**. العدد ليس السلاح. |
| «لماذا لا نبني صفحة لكل حي؟» | **432 كلمة حي → 3 مؤهلة (0.7%)** · Search Console: **0 نقرة**. صفر طلب. |
| «الناس يكتبون "فجدة" — لماذا لا نستهدفها؟» | جوجل يصحّح الإملاء بنموذج **680M معامل قبل الترتيب**. اختبرنا: نفس التسعة نتائج بنفس الترتيب. المكان الصحيح للخطأ الإملائي هو **Google Ads**. |
| «لماذا نصلح القديم قبل بناء الجديد؟» | لأن الجديد سيُبنى بنفس القالب الذي ينتج **97.37% تشابهاً**. إصلاح القالب أولاً = كل صفحة بعده سليمة. |
| «CI يبطئنا» | بلا CI، عشرة مطورين يكتشفون العطب **بعد** النشر. البوابات الست تكشفه في **90 ثانية**. |
| «الأسئلة الشائعة ما زالت مفيدة؟» | schema أُلغيت **2026-05-07**. لكن **النص المرئي** ما زال يخدم Passage Ranking. نكتبها للقارئ، لا للنتيجة المنسّقة. |
| «متى نرى نتيجة؟» | الأداء والفهرسة: **2–4 أسابيع**. الترتيب: **8–14 أسبوعاً**. من يعدك بأسرع من ذلك يبيعك وهماً. |
