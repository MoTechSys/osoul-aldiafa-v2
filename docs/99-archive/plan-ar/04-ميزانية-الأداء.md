# 04 — ميزانية الأداء

**القاعدة الحاكمة:** الميزانية **رقم**، لا رأي. تجاوزها = فشل CI = رفض الدمج.

**السياق الحاسم:** ~**96% من زوار هذا القطاع على الجوال**، وغالبهم على شبكة خلوية أثناء التخطيط لمناسبة. كل قرار أداء يُقاس على **Moto G Power / 4G بطيء**، لا على لابتوب المطوّر.

### قاعدة الانحدار (Regression Rule)
> أي PR يزيد **JS الأولي > 5 KB** أو **وزن أي صفحة > 30 KB** يجب أن يحمل تبريراً مكتوباً وموافقة القائد الفني. CI يعلّق الفرق تلقائياً.

## 3. الصور — أثقل بند وأسرع مكسب

### 3.1 خطة التخفيض الرقمية (الموجة 0 — مالكها D8)

| الخطوة | التوفير | النتيجة |
|---|---|---|
| حذف 5 نسخ الشعار المتطابقة (إبقاء واحدة) | **−800 KB** | مرجع واحد |
| حذف 4 أزواج مكررة (`hero-mobile`=`setup-10`، `hero-desktop`=`setup-5`، `hero-alt-2`=`team-10`، `hero-alt-1`=`product-9`) | **−700 KB** | 43 صورة حقيقية بدل 52 اسماً |
| ضغط 34 صورة > 100 KB إلى ≤ 100 KB | **≈ −2.5 MB** | |
| إعادة توليد `icon.svg` (172 KB → **< 5 KB**) | **−167 KB** | SVG متجهي حقيقي |
| إعادة توليد `icon-512.png` (130 KB → < 25 KB) | **−105 KB** | |
| توليد AVIF إلى جانب WebP | −20–30% إضافية | عبر `next/image` |
| **الإجمالي** | **≈ −4.3 MB** | **7.8 MB → < 3 MB** |

> ⚠️ **تنبيه محتوى مهم:** الأزواج المكررة تعني أن مخزوننا الحقيقي **43 صورة لا 52** — أقل 17% ممّا كان مفترضاً. هذا يشدّ الحاجة إلى أرشيف الصور من صاحب المشروع (الحاجب #1 في `02` §6). **لا تُوَلَّد صور بالذكاء الاصطناعي مهما ضاق المخزون (R1).**

### 3.2 قواعد التنفيذ الإلزامية

| # | القاعدة |
|---|---|
| P1 | ❌ ممنوع `<img>` خام. `next/image` **دائماً** — إلا SVG صغير مضمّن |
| P2 | `sizes` **إلزامي** مع `fill` — بلا `sizes` يُحمَّل أعرض مقاس |
| P3 | صورة LCP فقط: `priority` + `fetchPriority="high"` — **واحدة لكل صفحة** |
| P4 | كل ما دونها: `loading="lazy"` (افتراضي) |
| P5 | `width`/`height` أو `aspect-ratio` **دائماً** — منع CLS |
| P6 | `placeholder="blur"` للصور فوق الطية |
| P7 | تنسيق التسليم: **AVIF ثم WebP** — `formats: ['image/avif','image/webp']` |
| P8 | عرض المصدر الأقصى **1920px** — لا نخدم 4K لجوال |
| P9 | ❌ ممنوع صورة خلفية CSS للمحتوى المهم (تتأخر عن الاكتشاف) |
| P10 | كل صورة جديدة تمرّ بـ `08-خط-إنتاج-الصور.md` |

### 3.3 `next.config` — الإعداد المطلوب

```js
images: {
  formats: ['image/avif', 'image/webp'],
  deviceSizes: [375, 640, 768, 1024, 1280, 1600],
  imageSizes: [64, 96, 128, 256, 384],
  minimumCacheTTL: 31536000,
}
```

## 4. JavaScript — تقليل الحزمة

### 4.1 المصدر الحقيقي للثقل
**22 من 56 ملفاً (39%) تحمل `"use client"`.** كل واحد منها يُرسَل كاملاً إلى المتصفح.

| الإجراء | المالك | التوفير المتوقع |
|---|---|---|
| تفكيك `HomePageClient.tsx` (830 سطراً → 7 أقسام، 5 منها Server) | D4 | ~40% من JS الرئيسية |
| `dynamic()` للكاروسيل (Embla) مع `ssr: false` | D4 | ~14 KB مؤجّلة |
| `dynamic()` لأي مكوّن تحت الطية | D5 | متغيّر |
| استيراد Motion كمكوّنات محدّدة لا `import * as` | D4 | ~10 KB |
| حذف الأنيميشن اللانهائي حين `prefers-reduced-motion` | D5 | CPU/بطارية |
| مراجعة `BottomNav.tsx` (380 سطراً) | D5 | |

### 4.2 قواعد
| # | القاعدة |
|---|---|
| J1 | ❌ ممنوع مكتبة > 15 KB gzip بلا موافقة |
| J2 | ❌ ممنوع `moment` / `lodash` كاملاً — دوال أصلية أو استيراد ذرّي |
| J3 | ❌ ممنوع polyfill لمتصفحات ما قبل 2021 |
| J4 | ✅ `dynamic()` لكل ما تحت الطية |
| J5 | ✅ كل سكربت طرف ثالث `strategy="afterInteractive"` أو `lazyOnload` |
| J6 | ✅ **حد أقصى سكربتان خارجيان** في الموقع كله |

### 4.3 سكربتات الطرف الثالث — الميزانية القاسية
| السكربت | مسموح | الاستراتيجية |
|---|---|---|
| GA4 (`gtag`) | ✅ نعم — واحد فقط | `afterInteractive` ✅ (الكود سليم؛ المفقود متغيّر البيئة) |
| Meta Pixel / TikTok Pixel | ⚠️ يحتاج موافقة | `lazyOnload` |
| أي دردشة/ودجت | ❌ **مرفوض** | يقتل INP |
| خطوط خارجية (Google Fonts CDN) | ❌ **مرفوض** | نستخدم `next/font` ✅ (مطبَّق فعلاً) |

## 7. القياس — كيف نتحقق

### 7.1 في CI (كل PR)
```bash
npm run build                # يطبع أحجام الحزم
npx lhci autorun             # Lighthouse CI على 3 مسارات
node scripts/check-assets.mjs  # يفشل عند أي صورة > 100 KB أو public > 3 MB
```

### 7.2 `scripts/check-assets.mjs` — الفاحص الإلزامي (يكتبه D9)
يفشل عند: أي صورة > 100 KB · `public/` > 3 MB · أي ملفين بنفس بصمة md5 · أي `<img>` خام في `src/`.

### 7.3 أسبوعياً (D10)
- PageSpeed Insights **بيانات الحقل** لـ 3 مسارات
- تقرير Core Web Vitals في Search Console
- `curl -sI` للتحقق من `x-vercel-cache: HIT` و`content-encoding: br`

### 7.4 أمر التحقق السريع من TTFB
```bash
for i in 1 2 3 4 5; do
  curl -s -o /dev/null -w "%{time_starttransfer}\n" https://asoulaldiafa.com/
done
# المرجع المقيس: 0.047s — أي تراجع فوق 0.2s = تحقيق فوري
```
