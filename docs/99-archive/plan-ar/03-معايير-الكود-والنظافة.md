## 3. Server / Client — القاعدة الأهم للأداء

> **`"use client"` امتياز يُطلَب، لا افتراض يُورَث.**

### 3.1 شجرة القرار

```
هل يستخدم المكوّن useState / useEffect / useRef / onClick / motion / Embla؟
  ├── لا  → Server Component. لا تكتب "use client". ✅
  └── نعم → هل يمكن عزل الجزء التفاعلي وحده في مكوّن أصغر؟
        ├── نعم → اعزله. الأب يبقى Server. ✅ (النمط المطلوب)
        └── لا  → "use client" + تعليق إلزامي يشرح السبب
```

### 3.2 التعليق الإلزامي

```tsx
"use client";
// السبب: Embla Carousel يحتاج DOM حقيقياً — لا بديل خادمي.
// حجم الأثر: ~14 KB gzip. راجعه إن تغيّرت المكتبة.
```

CI يرفض أي `"use client"` بلا تعليق `// السبب:` في السطر التالي مباشرة.

### 3.3 الهدف الرقمي

| | اليوم | الموجة 0 | الأسبوع 14 |
|---|---|---|---|
| ملفات `"use client"` | 22/56 = **39%** | ≤ 30% | **≤ 18%** |

## 11. قائمة التحقق قبل أي PR

انسخها في وصف الـ PR وعلّم عليها:

```
- [ ] npm run typecheck  → 0 أخطاء
- [ ] npm run lint       → 0 أخطاء 0 تحذيرات
- [ ] npm run test       → كل الاختبارات خضراء
- [ ] npm run build      → ينجح، وحجم الحزمة لم يزد > 5 KB
- [ ] لم أعدّل ملفاً خارج ملكيتي (مصفوفة 10-بروتوكول)
- [ ] لم أضف "use client" بلا تعليق // السبب:
- [ ] لم أضف تبعية بلا موافقة
- [ ] لم أترك console / any / TODO بلا مالك وتاريخ
- [ ] كل صورة جديدة: WebP · < 100 KB · alt وصفي
- [ ] كل نص جديد: عربي فصيح · بلا رقم غير موثّق (R9)
- [ ] لم أكتب كلمة «فرع» (R2)
- [ ] فاحص التشابه أعطى < 60%
```
