## 1. جرد المخزون الحقيقي — الاكتشاف الذي يغيّر الخطة

فحصنا كل ملف في `public/` ببصمة md5. النتيجة **ليست ما كان مفترضاً**:

| المؤشر | القياس |
|---|---|
| حجم `public/` | **7.8 MB** |
| ملفات الصور | **64 ملفاً** = 7.04 MB |
| صور > 100 KB | **34 ملفاً** |
| أسماء webp | 52 |
| 🔴 **ملفات مكررة بايت-ببايت** | **9** |
| ✅ **صور حقيقية فعلياً** | **43 فقط** |

### 1.1 المكررات المكتشفة — بالبصمة

**المجموعة أ — خمس نسخ متطابقة من الشعار** (md5 `2d56512e14cce8d9f63c6d952d9b9fbd` · 200 KB لكل نسخة):
```
public/logo.webp
public/images/hero/logo.webp
public/images/hero/logo-gold.webp      ← اسم مضلّل: ليس ذهبياً مختلفاً
public/images/hero/logo-2.webp         ← اسم مضلّل: ليس نسخة ثانية
public/icons/logo-osoul.webp
```
**الهدر: 800 KB بلا أي فائدة.** والأسوأ: اسمان يوحيان بوجود بدائل تصميمية غير موجودة أصلاً — أوهما مطوّرين سابقين.

**المجموعة ب — أربعة أزواج متطابقة:**
| الملف | نسخة طبق الأصل من |
|---|---|
| `hero/hero-mobile.webp` | `setups/setup-10.webp` |
| `hero/hero-desktop.webp` | `setups/setup-5.webp` |
| `hero/hero-alt-2.webp` | `team/team-10.webp` |
| `hero/hero-alt-1.webp` | `products/product-9.webp` |

**الهدر: ~700 KB.**

### 1.2 الأثر الاستراتيجي — يجب أن يعرفه صاحب المشروع

> **مخزوننا الحقيقي 43 صورة لا 52 — أقل بـ17% ممّا افترضته الخطة.**
> وصور الهيرو الأربع **ليست صوراً خاصة بالهيرو أصلاً** — هي إعادة استخدام لصور المعرض.

وبما أن **R1 يمنع التوليد**، فإن **أرشيف الصور من صاحب المشروع هو الحاجب رقم 1 في المشروع كله** (`02` §6). الموجة 1 — كسر القالب — **لا يمكن إنجازها بصور معادة الاستخدام**، لأن العنصر الإلزامي #2 في `07` §7.2 هو «صور حقيقية من مناسبات في تلك المدينة».

| **الإجمالي** | | **7.8 MB → < 3 MB** |

### 2.1 أوامر الكشف — أعِد تشغيلها للتحقق

```bash
cd /home/user/webapp

# 1) كشف المكررات بالبصمة
find public -type f \( -name '*.webp' -o -name '*.png' -o -name '*.jpg' \) \
  -exec md5sum {} + | sort | awk '{print $1}' | uniq -d | while read h; do
    echo "── بصمة مكررة: $h"
    find public -type f -exec md5sum {} + | grep "^$h" | awk '{print "   " $2}'
  done

# 2) كل صورة > 100 KB
find public -type f -size +100k -printf '%k KB\t%p\n' | sort -rn

# 3) الحجم الكلي
du -sh public/
```

## 3. المرحلة 2 — المعالجة القياسية

### 3.1 مواصفات الإخراج الإلزامية

| البند | القيمة |
|---|---|
| التنسيق الأساسي | **WebP** (المصدر) — AVIF وWebP يولّدهما `next/image` |
| الجودة | **82–85** (لا 100 — الفرق غير مرئي والوزن مضاعف) |
| أقصى عرض | **1920px** (هيرو) · 1200px (معرض) · 800px (بطاقات) |
| **حد الحجم** | **≤ 100 KB** — استثناء وحيد: صورة LCP ≤ 120 KB بتبرير مكتوب |
| نسب معتمدة | 16:9 · 4:3 · 1:1 فقط (`06` §4.3) |
| الملف الشخصي اللوني | **sRGB** |
| البيانات الوصفية | ❌ **تُزال** (EXIF/GPS) — خصوصية + وزن |

### 3.2 أوامر المعالجة المرجعية

```bash
# ضغط دفعة إلى ≤ 100 KB مع الحفاظ على النسبة
for f in public/images/**/*.webp; do
  cwebp -q 83 -resize 1600 0 -metadata none "$f" -o "${f%.webp}-opt.webp"
done

# تحقّق: لا شيء فوق 100 KB
find public -type f -size +100k | wc -l   # يجب أن يعطي 0
```

### 3.3 هيكل التسمية الجديد

```
public/images/
├── brand/       logo.webp (نسخة واحدة فقط)
├── hero/        hero-home.webp · hero-jeddah.webp · …
```

**قاعدة التسمية:** `{فئة}-{مدينة إن وُجدت}-{رقم}.webp` · إنجليزية · `kebab-case` · بلا مسافات ولا عربية في اسم الملف.

## 4. المرحلة 3 — الصور المرخّصة (المسار 3)

### 4.1 التراخيص المقبولة فقط
| ✅ مقبول | ❌ مرفوض |
|---|---|
| CC0 / Public Domain | أي صورة بلا ترخيص واضح |
| CC BY (مع الإسناد) | نتائج بحث الصور العامة |
| CC BY-SA | لقطات من مواقع منافسين |
| مرخّص تجارياً بإيصال شراء | **أي مزوّد تجاري بلا شراء** (Getty · Shutterstock · Alamy · iStock · Adobe Stock) |

> ⚠️ **تحذير قانوني:** استخدام صورة من مزوّد تجاري بلا ترخيص = **مخاطرة قانونية حقيقية**، وشركات الصور تلاحق فعلياً. عند الشك — **لا تستخدمها**.

### 4.2 التعديل الإلزامي — «كي لا تتطابق»
كل صورة مسحوبة **يجب** أن تمرّ بثلاثة تعديلات على الأقل:

| # | التعديل |
|---|---|
| 1 | **قصّ/تأطير** مختلف عن الأصل (تغيير التكوين لا مجرد تصغير) |
| 2 | **تدرّج لوني** يطابق هوية العلامة (Onyx/Champagne — `06` §1) |
| 3 | **طبقة أو عنصر علامة** (تعتيم متدرّج · إطار ذهبي رفيع · شعار خفيف في الزاوية) |
| 4 | (اختياري) تعديل نسبة العرض للنسب المعتمدة |

⚠️ **حدود التعديل:** ❌ ممنوع فلتر ذهبي فوق الوجوه (`06` §4.3 V5) · ❌ ممنوع تشويه النسب · ❌ ممنوع تعديل يُظهر شيئاً لم يحدث (كذب بصري).

### 4.3 سجل المصادر الإلزامي — `docs/image-sources.json`

كل صورة غير مملوكة تُسجَّل. **بلا سجل = بلا دمج.**

```json
{
  "cities/jeddah-02.webp": {
    "source": "https://example.org/photo/12345",
    "license": "CC BY 4.0",
    "author": "اسم المصوّر",
    "attribution_required": true,
    "downloaded": "2026-08-20",
    "modifications": ["قصّ 16:9", "تدرّج Onyx", "إطار ذهبي 2px"],
    "used_in": ["/sababin-qahwa-jeddah"]
  }
}
```
حين يكون `attribution_required: true` → الإسناد ظاهر في صفحة `/credits` أو تحت الصورة.

## 5. النص البديل (`alt`) — أصل سيو لا حقل إلزامي

**الحالة اليوم:** ✅ **صفر صورة بلا `alt`** — إنجاز يجب حمايته.
**الفجوة:** كثير من النصوص البديلة **قالبية** («صبابين قهوة في {المدينة}») — تكرّر مشكلة التشابه على مستوى الصور.

| # | القاعدة |
|---|---|
| A1 | **صِف ما في الصورة فعلاً**، لا ما تريد ترتيبه |
| A2 | **6–14 كلمة** عربية |
| A3 | ❌ ممنوع البدء بـ «صورة» أو «صورة لـ» |
| A4 | ❌ ممنوع حشو كلمات مفتاحية |
| A5 | ✅ **فريد لكل صورة** — ❌ ممنوع نص بديل مكرر بتبديل المدينة |
| A6 | `alt=""` للصور الزخرفية البحتة فقط |
| A7 | صورة داخل رابط: يصف **وجهة الرابط** |
| A8 | يذكر المدينة **فقط إن كانت المدينة مرئية فعلاً** في الصورة |

```
✅ صبّاب يقدّم القهوة العربية في دلة نحاسية لضيوف حفل زفاف
✅ طاولة ضيافة مجهّزة بالتمور والفناجين قبل استقبال المعزّين
❌ صورة قهوجيين جدة صبابين جدة ضيافة جدة
❌ صبابين قهوة في {المدينة}   ← قالب
```

## 7. سير عمل إضافة أي صورة جديدة

```
1. المصدر؟
   ├── أرشيف صاحب المشروع → 3
   ├── مرخّصة → سجّلها في image-sources.json ثم عدّلها (§4.2) → 3
   └── ذكاء اصطناعي → ⛔ توقّف. مرفوض (R1).
2. الترخيص موثّق؟ لا → توقّف.
3. عالجها: النسبة المعتمدة · ≤ 1920px · WebP q83 · بلا EXIF
4. تحقّق: ≤ 100 KB
5. سمِّها بالنمط المعتمد وضعها في مجلدها
6. سجّلها في src/lib/images.ts
7. اكتب alt وصفياً فريداً (§5)
8. شغّل npm run check:assets → يجب أن يمرّ
9. PR: أرفق الحجم قبل/بعد والمصدر والترخيص
```

## 10. رسالة إلى صاحب المشروع

> نظّفنا وضغطنا ما لدينا، وسنخفض حجم الصور من 7.8 ميغابايت إلى أقل من 3 — وهذا مكسب أداء مؤكد.
>
> لكن هناك حقيقة يجب أن تكون واضحة: **مخزون الصور الحقيقي 43 صورة لا 52**، وأربع من «صور الهيرو» ليست إلا نسخاً من صور المعرض. ولأننا **لن نولّد صوراً بالذكاء الاصطناعي** (كما أمرت)، فإن **الموجة 1 — وهي أهم موجة في الخطة كلها — متوقّفة على أرشيف صورك الحقيقية**.
>
> **المطلوب:** 3 صور على الأقل لكل مدينة، من مناسبة حقيقية خدمتموها هناك. صور الجوال العادية **كافية تماماً** — الأصالة أهم من جودة العدسة، وجوجل والعميل كلاهما يميّز الصورة الحقيقية من صورة المخزون.
>
> بدون هذا الأرشيف سنكسر التشابه بالنص وحده — وهو ممكن، لكنه **أضعف بكثير** وأبطأ في النتيجة.
