## 🧭 الحقائق الحاكمة (احفظها)

| # | الحقيقة | لا تخالفها لأن… |
|---|---|---|
| ١ | **نطاق الخدمة = ٥ مدن فقط**: جدة · مكة · المدينة · ينبع · بدر | مصدرها الوحيد `CITIES` في `src/lib/localPages.ts`، ومنها تُشتَق `SERVICE_AREAS` (GeoCircle). أي نص يقول «جميع مناطق المملكة» **يناقض بياناتك المهيكلة أمام جوجل** |
| ٢ | **لا صفحات أحياء** | ٤٠ صفحة مدينة ⇒ نصفها Doorway ⇒ **−٦٣٪ زيارات في ٣٠ يومًا**. موثّق |
| ٣ | **لا كلمة «فرع»** | الخدمة **متنقّلة** ولا مقرّات ثابتة ⇒ `ProfessionalService` لا `LocalBusiness` |
| ٤ | **التصميم الأول فقط** | قرار صاحب المشروع: «التصميم حقك الحالي ولا تدخله أبداً» — يقصد `/luxe-demo` |
| ٥ | **لا قائمة أسعار** | «كل واحد على حسب». الشفافية تُحقَّق بشرح **كيف** يُبنى السعر |
| ٦ | **لا رقم غير مُتحقَّق** | لا «١٠٠٠ عميل» ولا «١٥ سنة خبرة» بلا إثبات |
| ٧ | **CSS للحركات فوق الطية** | `motion` بـ `initial={{opacity:0}}` يُخفي المحتوى حتى الـhydration ⇒ LCP ٢٢٥٢ms |
